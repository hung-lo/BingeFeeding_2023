# BingeFeeding_2023
This repository hosts code and data used for the [Lo et al. 2023 preprint](https://www.biorxiv.org/content/10.1101/2023.10.17.562714v2.full) on binge feeding, [pdf link](https://www.biorxiv.org/content/10.1101/2023.10.17.562714v2.full.pdf). 
This manuscript is now published in [Neuron](https://doi.org/10.1016/j.neuron.2025.07.020) (2025).

Processed data (Ca2+ traces, behavioral readouts eg, lick/pump events, optogenetics results, etc.) can be found [here](https://zenodo.org/records/15824561)
